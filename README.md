# Money Tracker

A simple chore money tracker built by Stephen. Every entry is saved only on the phone that uses it, nothing is sent anywhere.

## Put it online (GitHub Pages)
1. Upload every file in this folder to the root of this repo.
2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. After a minute or two the app is live at `https://<your-username>.github.io/<repo-name>/`.

## Install on iPhone
1. Open the link in Safari.
2. Tap Share (in iOS 26 it sits under the three dots), then Add to Home Screen.
3. Always open it from the home screen icon. The home screen app keeps its own data, separate from the Safari tab.

## Keep data safe
Use "Jobs and backup" > "Save a backup" now and then and save the file to Files or iCloud Drive. "Restore a backup" brings it all back.
